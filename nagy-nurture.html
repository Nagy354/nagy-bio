final project

Dwell-time filtering for warehouse security cameras

Implementation of Dwell-Time Logic on an ESP32-CAM for False Alarm Reduction in an Edge-Cloud Based Warehouse Security System

Motion sensors alone can't tell a loiterer from someone walking past, so this system adds two more filters before it bothers anyone with a phone notification: an ESP32-CAM has to see continuous presence for 12 seconds before it's worth a second look, and only then does a frame get sent off for object detection.

architecture
PIR sensor → dwell timer (ESP32-CAM) → YOLOv8n inference (DigitalOcean)
dwell threshold
12 seconds of continuous presence
accuracy
68.6% weighted average across 50 trials
false-positive rejection
100% of non-loitering attempts correctly ignored
